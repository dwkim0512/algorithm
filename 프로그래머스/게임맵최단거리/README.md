# 문제 설명
좌표 (1,1)에서 좌표 (5,5)에 도착하는 최단거리 구하기
벽이 존재하며 막혀있지 않은 곳만 통로

# 문제 접근
최단거리 탐색은 주로 BFS를 활용한다.
DFS로도 최단거리 탐색을 풀 수 있지만, 이동 횟수(재귀 depth)를 매번 전달하며 최단 거리를 갱신해줘야한다.

BFS 기본 로직
1. 현재 위치를 큐에 넣는다.
2. 현재 위치를 큐에서 뺀다.
3. 방문할 수 있는 모든 위치를 큐에 넣는다.
4. 상대 진영인 (n, m)에 도착할 때까지 반복한다.
5. 방문할 수 있는 위치는 '1'이다.

BFS 기본 구조에서, 이동할 수 있는 칸을 상,하,좌,우로 탐색하며 거리를 센다.
