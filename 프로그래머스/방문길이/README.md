# 문제 설명
u,d,l,r로 방향을 이동하고, 처음 지나간 길 개수 카운트
# 문제 접근
dx, dy를 통해 `dirs`배열 내부의 이동 명령을 수행한다.

다음 이동 좌표가 범위를 넘는다면 해당 좌표를 방문하지 않고 다음 명령으로 넘어간다.

`set`을 활용해 처음 방문한 길(여기서 처음 방문한 길이란 현재 좌표와 다음 방문할 좌표의 관계가 된다.)을 양방향으로 `visited`배열에 추가한다.

`nx`, `ny`를 현재 좌표로 변경하고 다음 명령을 수행한다.


# 회고
문제를 풀지 못했다. 경로를 값으로 표현해야 하고, 그걸 튜플로 저장하고 중복을 피하기 위해 set을 사용해야 하는 것을 떠올리지 못했다.
양방향으로 저장해서 반대 방향의 경우도 보장하는 것도 못 떠올리고, 조건을 만족하지 못 할 때 다음 반복으로 넘어가는 continue도 생각 못해서 아쉽다.
