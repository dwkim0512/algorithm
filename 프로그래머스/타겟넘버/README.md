# 문제 설명
`numbers` 배열을 적절히 더하거나 빼서 `target`을 만들 수 있는 개수를 return한다.

# 문제 접근
dfs를 활용한 완전 탐색

현재 합을 기준으로 다음의 두 가지 케이스를 고려할 수 있음

* 현재 합 + 배열의 다음 원소
* 현재 합 - 배열의 다음 원소

dfs 종료 조건 떠올리기: 배열의 끝에 도달했을 때

개수 증가 조건 떠올리기: 배열의 끝에 도달했을 때, 합이 `target`인 경우

# 회고
풀이가 한 번에 잘 안나와서 인터넷을 참고해서 풀었다. 풀고 나서 이게 왜 dfs일지 생각해보고, 문제를 어떻게 접근했다면 풀었을 수 있을 지 생각해봤다.

O(2^n)
