# 문제 설명
2명 태울 수 있는 보트
무게의 합이 limit을 넘지 않는 선에서
최소 보트 수 반환

# 문제 접근
1. 배열 정렬
2. 0번 인덱스 값 + -1번 인덱스 값
3. 무게를 초과하지 않는다면 보트 수 +1하고 배열에서 제거
4. 초과한다면 무거운 사람의 포인터를 앞으로 땡기기

# 회고
로직은 쉽게 떠올렸는데 코드로 작성하는 시간이 오래 걸렸다.
특히 조건을 만족할 때 앞 뒤로 다 포인터를 땡겨주어야 하는 것 구현이 안됐다.
조건을 만족하지 못하는 경우 무거운 사람은 가장 가벼운 사람과도 탈 수 없다는 뜻이 되므로 혼자 타야돼서 해당 포인터를 땡겨주면 되는 것이었다.
