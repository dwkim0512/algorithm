# 문제 설명
`begin`에서 `target`단어를 만드는 데 필요한 최소 변환 횟수

변환은 1회에 1글자만 가능
# 문제 접근
최단거리를 찾아야 하기 때문에 bfs

+ 현재 위치에서 한 글자 변환으로 접근할 수 있는 단어들을 먼저 고르자라는 생각이 들어서 bfs 연상

기본 bfs 구조에서 words 안에 존재하면서 한 글자만 다른 단어들을 queue에 삽입

한글자만 다른 걸 어떻게 찾나?

-> 카운트를 도입해서 다른 글자가 1개인 경우 queue에 삽입 후 거리 증가

최단거리를 보장해야 하기 때문에 used 배열을 활용해 한 번 queue에 들어간 단어는 다시 들어가지 못하도록 보장
# 회고
전체적으로 문제 접근 방식이 좋았던 것 같다. 코드가 깔끔하거나 잘 풀었는지는 모르겠지만 한 글자 다른 단어를 찾기 위해 count 변수를 도입하고, 글자를 인덱싱하기 위해 enumerate도 잘 활용한 것 같다.
# 시간 복잡도
O(n^2)
