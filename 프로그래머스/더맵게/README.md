# 문제 설명
`섞은 음식의 스코빌 지수 = 가장 맵지 않은 음식의 스코빌 지수 + (두 번째로 맵지 않은 음식의 스코빌 지수 * 2)
`
모든 배열값이 k가 넘도록
# 문제 접근
1. 리스트를 파이썬 heapify로 힙으로 변환한다.
2. 앞에서 한개를 pop하고 k를 넘지않는다면 한개 더 pop해서 공식 수행, result += 1
3. k를 모두 넘는다면 result 반환

# 회고
문제는 풀어서 맞췄는데 두 가지 아쉬운 점이 있었다.
자료구조 heap을 쓰는 문제인걸 몰랐다면 일반적인 배열로 풀려고 접근했을 것이다.
제한사항의 K가 10억 가까이 되는 수인 것을 확인하는 습관이 필요하다.
두 번째 아쉬운 점은 heapq 문제를 몇 번 풀어봤었는데, 기본 문제임에도 사용 방법이 기억이 안 난다는 것이었다. 해당 자료구조를 잘 활용할 수 있도록 노력해야겠다.

# 시간 복잡도
heapq 자료구조 알고리즘: O(logn)
